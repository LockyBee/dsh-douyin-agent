# 抖音网页版

默认引导用户打开 DSH“设置 → 刷抖音”，通过按钮配置和运行，不要求输入聊天指令或复制工具名。插件使用 DSH 已配置的模型；独立软件可保留任务对话并使用自己的 API Key。安装及验收边界见 [插件说明](../docs/plugin.md)。当前 1.3 源码为原生 v10、32 项兼容工具，软件 1.3 尚未打包发布或实机验收。

本人保存人格、允许时段和单轮分钟数，点击“打开抖音”并手动登录，再点击“开始新一轮”“开始自主观看”。工具、模型和记忆不能自行开始或延长轮次。每天按 Asia/Shanghai 时段门控，视频截止与请求上限任一先到便停；重启不恢复自主循环。自主观看默认每轮最多 30 次模型请求，可设 1–100，同轮停止重开不清零，两入口每日合计最多 200 次，评论生成也占此额度。

软件和插件按同一位置记录共用记忆。手编人格与生成区分开；兴趣按真实媒体进度、观看比例、停留、快划及已确认分享更新，不能看到某主题就学成喜欢。代理兴趣不是用户偏好，不能带出 QQ、其他联系人或私密记忆，也不能增加权限。

## 可选外发与日报

- 私信自动回复：仅处理本人保存的最多两位已关注个人联系人，启动先建旧消息基线，随后只处理可靠新消息。模型只读当前会话相关消息与手编人格风格，不读其他联系人、QQ、自动兴趣或观看记录。身份、方向、消息指纹或发送回执不明时暂停，不盲目重发；服务是否启动以实际状态为准。
- 自动续火花：默认关闭，由本人保存许可、时段并启动。按手编人格生成短问候，每位许可好友每日最多尝试一次。当天已有可靠发出互动、日期不明或有待回复消息时跳过；问候送达不等于已核实平台火花续上。
- 自主分享：默认关闭，每日默认 3 次，可设 1–20。开启后，大肥鱼在有限观看中自己选择当前实际观察作品和现有许可好友，通过官方界面发送作品卡片，不要求逐次选片选人。不改发文字链接、人格或私密记忆。
- 自主评论：默认关闭，每日默认 3 次（1–20）、每轮默认 1 次（1–3）。只在上述有限自主观看及许可内决定是否评论当前作品；正文由另一次仅含本作品实际画面、标题和作者的请求生成，不读取人格、兴趣、联系人、QQ 或私信。最多 200 字，不含 @、链接、私人数据或现实承诺。普通手动工具没有直接评论入口。
- 外发预留即扣次数，失败、重启或人工核对不返还；同作品评论不自动重复。结果不确定时本人核对原记录，再在页面记录结果，不触发重发。真实评论 DOM 尚待验收，缺少可核官方输入区或按钮时提示手动打开评论面板，不猜测成功。
- 视频日报只汇总本机留存的视频标题、作者、规范链接、可核进度与互动，并注明覆盖范围，不读取人格正文、私信或 QQ，不调用模型。保存到 `memoryDir/reports/videos/YYYY-MM-DD.md`；事实不变幂等，手编稿冲突时保留原文。

静默开关与有限时钟共用：持续静音但不改用户音量、不主动置前，核实整个窗口受管且无登录验证后才尝试最小化。关闭不主动弹出窗口；用户可点“打开抖音”显示。它仍是有窗口 Edge，不是 headless，不伪造页面可见性；真实抖音最小化后的持续播放尚待验收，不能保证后台不断播。

## 兼容工具与维护

日常用设置按钮。确需兼容工具时先读 `douyin_video_limits_status`；只有已有有效有限轮次才能浏览。DSH 与软件使用独立命名标签页，共用专用 Edge 登录资料。

- `douyin_search` 返回可见结果 index、作品 ID、作者和文案；`douyin_open_video` 打开当前结果。`douyin_next` / `douyin_previous` 仅在 `changed=true` 时算确认换片。
- `douyin_observe` 提供实际采样附件，以 `imageStatus` 为准；少量帧不能证明看完整条或听懂声音。`douyin_play` / `douyin_pause` 回读实际播放状态。
- `douyin_media_status` 读取开关与后端。音频可不接入，默认关闭；`douyin_listen` 仅在用户开启后录取当前视频最多十秒音轨，不录麦克风或其他程序。MiMo / MiniMax Key 只是可选音频配置，不是刷视频必需项。
- `douyin_chat_observe` 只采集许可会话中指定表情或分享卡片。分享视频采样受视频时间限制，封面不等于全片；普通图片、收到的语音等未支持类型不得假称已理解。
- `douyin_forward_video` 普通模型分支只提示人工入口；旧手动转发仍需明确选片选人授权。自主分享通过独立许可服务，不借普通工具扩大权限。
- `douyin_recall` 检索中央记忆，`douyin_remember` 保存用户要求的笔记；历史记录不是用户确认的事实。日报工具仅生成或读取报告，不启动观看。

工具未加载时按[插件安装说明](../docs/plugin.md)处理，不能用旧 Playwright CLI 登记或窗口存在推断加载成功。CLI `douyin.ps1` 和热加载包只作兼容维护，不能绕过界面许可、视频时限或发送核对。GPT 与 DSH 合作使用上级 `bridge.ps1`，轮数或尝试耗尽后不得新建任务绕过预算。
