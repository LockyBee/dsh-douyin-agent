# 1.3 功能复用与验证范围

核对日期：2026-10-15。

本次沿用既有 Playwright 专用浏览器、视频限时、人格卡、实际观看行为、官方作品卡片转发和联系人许可。新增功能不另装一套浏览器或 DSH，不读取主浏览器资料。

## 安装、设置与日报

参考 [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)，核对提交 `a047fde1df2be1ec1d9d7551aa0b5eae6626b319`，MIT，2026-10-15 有更新。借鉴标准 bundle 的安装声明、`settings.section` 原生设置入口，以及将实际浏览结果保存为 Markdown 日报的流程。没有打包其 Python、B 站 MCP、字幕抓取、登录凭证或定时 headless DSH 任务，也没有把其字幕阅读能力算成我们的视频观察能力。

本项目自行实现抖音设置接口、原生前端、同源会话校验、共享人格编辑、现有记录汇总和手改保护。日报只读视频事实，既不调用模型也不读取人格正文、私信、QQ。标准 bundle 入口和旧 file URI 热加载分开安装，避免重复注册。

## 自动续火花

核对 [HRuiCcc/dy-xuhuohua](https://github.com/HRuiCcc/dy-xuhuohua)（MIT，提交 `c3842f6321ac21c2af7590e69e0df94dfefefe0c`，2026-09-08）和 [dr-190/ScriptCat-Douyin-Fire-Helper](https://github.com/dr-190/ScriptCat-Douyin-Fire-Helper)（MIT 与 NOTICE，提交 `a1a86eb83267665d53b10290fd1776155bd2a67f`，2026-10-02）。它们依赖各自服务或脚本管理器，联系人身份、日期和发送确认方式不能直接替代现有安全边界，因此不引入运行依赖或复制其发送实现。

复用本项目的精确联系人身份、消息日期证据和发送回读，新增共用调度与去重账本。默认关闭，沿用已有两位许可好友；每天每好友最多尝试一次。当天已有可靠发出互动就跳过，日期不明、待回复或发送不确定时不自动重试。问候按手编人格生成；消息送达不代表已核实平台火花增加。

## 评论与静默观看

评论沿用已有有限视频轮次和真实作品证据，自行实现独立公共评论请求及发布核对。只给正文生成请求当前作品标题、作者与实际画面，不提供人格、兴趣、私信、QQ 或联系人。评论默认关闭；独立每日与单轮次数，预留后不返还，同作品永久去重，结果不明暂停。开发验收不向真实抖音账号公开发评论。

静默观看沿用专用 Edge 与 CDP。开启后静音，不主动置前；只有核对为全受管且没有登录验证的专用窗口才尝试最小化。保留真实播放与采样，不伪造页面可见性，不自动延长轮次。当前仍是有窗口浏览器，真实抖音最小化后的持续播放须另外验收。

本地合成页面、SDK 和单元测试不能替代当前 DSH 加载或真实抖音验收。各项实测结果以本次报告为准。

## 2026-10-16 设置页修复

继续复用已有 DSH 原生 Button、Input、主题与设置插槽，将内容分为基础设置、视频观看、好友互动、公开评论、音频与密钥、观看日报，不增加前端运行依赖。模型下拉使用当前安装的 LlmRuntime.listModels 已配置目录；不调用 discoverModels 或模型生成，缓存目录避免轮询重复读取。

浏览器启动复用已有桌面资源中的独立 Node，并核对实际版本，拒绝将 Electron 主程序作为 Node。找不到已有 Node 时才要求安装或显式指定，不自动下载运行环境。MiMo/MiniMax 保存入口复用独立软件已有原子写入器，提取到共享媒体模块；只在本机保存，不自动开启音频或执行云请求。
