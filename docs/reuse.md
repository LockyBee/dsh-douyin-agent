# 1.3 功能复用与验证范围

## 2026-10-29 分享视频续看

复用现有群视频队列、聊天模型、原生画面证明、共享人格兴趣与分镜合图，不增加下载器或模型服务。新增本机逐批回调和明确的continue/stop决策，单批采集间隔可变，整条不设固定总时长或总批次。短批次、超时和图片内存边界只管理一次操作；每日时段和预算继续由原VideoLimits管理。没有自主决策的短采样不再计为观看完成，播放到结尾也不冒称理解了每一帧或音轨。

## 2026-10-29 主对话反馈与新增issue核对

复用官方npm发布的DSH 0.2.1-rc.3前后端及Node 24.21.0，在独立配置和合成模型下检查客户端，不把测试依赖加进产品。官方SDK为MIT，Node和发布包完整性记录保存在本地复现目录。普通启动、标准bundle挂载、打开设置后与同页热启停都显示合成正文；原邮件的正文消失尚未复现。缩小settings-general依赖的隔离候选没有合入，也没有替换宿主聊天渲染器。

新增视频问题沿用现有ChatBrowser和readPageState：移除匿名永久play暂停监听，仅暂停当次背景视频；搜索作者复用播放器已有长度与NUL边界，PersonaMemory严格输入校验保持。真实Edge合成视频的进度、会话内视频持续播放和超长DOM作者分别回归，不能替代报告者机器复测或新的内存长测。

## 2026-10-28 已有适配层修复

本轮继续使用仓库既有的消息水位、许可身份、真实输入见证、共享发送锁、视频时限与独立运行包。复用了已安装 Node 的 WebSocket 和原生 CDP，仅替换无缓存暂停时的短连接方式；没有增加依赖、换个人浏览器资料或引入第三方聊天机器人。群聊只从已渲染会话的固定数据路径读取稳定标量，行与头部交叉核对；评论本人身份从当前登录导航的固定资料读取，不从模型参数或昵称推断。

本地源码全套回归、真实账号只读核验、实际外发与长时间内存测试分别记录在 [当前验收矩阵](../verification/local-final-20261028/RESULT.md)。短时连接压力和隔离用例不能替代两小时实际运行；未知送达仍保留核对记录，不盲目重发。

## 2026-10-27 浏览器内存与后台恢复

继续复用 BrowserController、ChatBrowser、现有页面归属锁、消息订阅清理和好友互动退避，不增加依赖。后台路径只重连已有专用浏览器和聊天页，关闭关注核对导航及消息面板自动打开；人工读取保留准备页面的能力。初始化失败只回收本次新建且仍归本入口的页面，登录或验证页面保留。观看决策保留短搜索词兼容，但分享、评论及非法参数继续校验；人工许可也不能接受自称稳定却残缺或冲突的身份字段。

内存回归使用真实 Edge 和完全拦截网络的合成页面，重复后台读取和订阅清理，记录页面、文档、监听器及 JavaScript 堆。不将它写成真实抖音账号的长期运行结果。

2026-10-24的1.4.5候选继续复用本仓库的 Playwright、消息水位、发送协调器和评论证据。新增群聊显式许可及昵称触发、无正文通知唤醒和新版页面控件识别；不新增依赖。以下历史记录仍对应原核对日期，当前效果另见[本版验证](verification/issues-20261024.md)。

核对日期：2026-10-15。

本次沿用既有 Playwright 专用浏览器、视频限时、人格卡、实际观看行为、官方作品卡片转发和联系人许可。新增功能不另装一套浏览器或 DSH，不读取主浏览器资料。

## 安装、设置与日报

参考 [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)，核对提交 `a047fde1df2be1ec1d9d7551aa0b5eae6626b319`，MIT，2026-10-15 有更新。借鉴标准 bundle 的安装声明、`settings.section` 原生设置入口，以及将实际浏览结果保存为 Markdown 日报的流程。没有打包其 Python、B 站 MCP、字幕抓取、登录凭证或定时 headless DSH 任务，也没有把其字幕阅读能力算成我们的视频观察能力。

本项目自行实现抖音设置接口、原生前端、同源会话校验、共享人格编辑、现有记录汇总和手改保护。日报只读视频事实，既不调用模型也不读取人格正文、私信、QQ。标准 bundle 入口和旧 file URI 热加载分开安装，避免重复注册。

## 自动续火花

核对 [HRuiCcc/dy-xuhuohua](https://github.com/HRuiCcc/dy-xuhuohua)（MIT，提交 `c3842f6321ac21c2af7590e69e0df94dfefefe0c`，2026-09-08）和 [dr-190/ScriptCat-Douyin-Fire-Helper](https://github.com/dr-190/ScriptCat-Douyin-Fire-Helper)（MIT 与 NOTICE，提交 `a1a86eb83267665d53b10290fd1776155bd2a67f`，2026-10-02）。它们依赖各自服务或脚本管理器，联系人身份、日期和发送确认方式不能直接替代现有安全边界，因此不引入运行依赖或复制其发送实现。

复用本项目的精确联系人身份、消息日期证据和发送回读，新增共用调度与去重账本。默认关闭，沿用已有两位许可好友；每天每好友最多尝试一次。当天已有可靠发出互动就跳过，日期不明、待回复或发送不确定时不自动重试。问候按手编人格生成；消息送达不代表已核实平台火花增加。

## 评论与静默观看

评论沿用已有有限视频轮次和真实作品证据，自行实现独立公共评论请求及发布核对。只给正文生成请求当前作品标题、作者与实际画面，不提供人格、兴趣、私信、QQ 或联系人。评论默认关闭；独立每日与单轮次数，预留后不返还，同作品永久去重，结果不明暂停。开发验收不向真实抖音账号公开发评论。

静默观看沿用专用 Edge 与 CDP。开启后静音，不主动置前；只有核对为全受管且没有登录验证的专用窗口才尝试最小化。保留真实播放与采样，不伪造页面可见性，不自动延长轮次。当前仍是有窗口浏览器，真实抖音最小化后的持续播放须另外验收。

本地合成页面、SDK 和单元测试不能替代当前 DSH 加载或真实抖音验收。各项实测结果以本次报告为准。

## 2026-10-24 私信媒体

继续复用现有 Playwright、消息身份与发送协调器，以及 MediaAdapter 的本地 Whisper、ffmpeg 和缓存模型，不新增依赖。网页语音没有原生 audio 标签时，只读取该条已渲染语音控件固定位置的自有资源值；不执行 getter、播放器回调或遍历全局状态。资源仍受消息绑定、平台来源、体积、时长和取消检查约束。表情优先使用网页名称，普通图片仅采对应消息区域。未识别到对白单独标记，不把空结果当成语音理解成功。

## 2026-10-16 设置页修复

继续复用已有 DSH 原生 Button、Input、主题与设置插槽，将内容分为基础设置、视频观看、好友互动、公开评论、音频与密钥、观看日报，不增加前端运行依赖。模型下拉使用当前安装的 LlmRuntime.listModels 已配置目录；不调用 discoverModels 或模型生成，缓存目录避免轮询重复读取。

浏览器启动复用已有桌面资源中的独立 Node，并核对实际版本，拒绝将 Electron 主程序作为 Node。找不到已有 Node 时才要求安装或显式指定，不自动下载运行环境。MiMo/MiniMax 保存入口复用独立软件已有原子写入器，提取到共享媒体模块；只在本机保存，不自动开启音频或执行云请求。

## 2026-10-24 自动保存与每日用量

继续复用现有设置页、VideoLimits、ScheduledWatch、ChatService、AutonomousShare 和 UsageLedger，不新增运行依赖。统一开关协调原有回复和作品分享；自动续火花停止提供启动入口，保留旧发送记录供核对。每日时长使用真实播放器状态和有界采样租约累计，请求沿用共用账本，平台返回的 Token 每次响应后立即追加。前端复用 React 和现有控件，增加带草稿版本与回读确认的自动保存；未返回 Token 的请求只显示进行中，不估算消耗。

## 2026-10-24 好友维护与状态栏

继续复用既有ChatBrowser、MessageIdentityTracker、ChatService、FriendInteractions、UsageLedger和React控件，不新增运行依赖。补充当前会话虚拟列表遍历、维护恢复证明、真实心跳状态推导及按钮联动。没有把平台未呈现的群或未核实身份当作可用联系人；实际群外发仍需有被许可的真实群会话才能验收。

## 2026-10-24 稳定身份与并发修复

复用本仓库的 ChatBrowser、许可账本、发送回读、专用标签及文件锁，不增加依赖。采用当前已渲染会话节点的固定身份字段和公开个人主页标识，不依赖昵称或头像。补充身份绑定版本、同一原会话的迁移、切换稳定等待、进程内公平排队及跨入口标签认领锁。稳定标识不足时不猜测对应账号；既有待发记录也不凭显示名恢复发送。

这些改动属于现有适配层的缺失部分，未引入第三方社交机器人。真实网页页面结构仍可能变化；本地合成用例验证边界，当前账号实测另见本次验证记录。

## 2026-10-24 私信人格与计时修复

继续复用 ChatAgent、共用手编人格、当前会话许可和 VideoLimits，不新增依赖。调整角色提示与当前会话的最少上下文，不将完整兴趣证据或 QQ 历史注入私信。计时沿用两秒采样租约，修复多次取时造成的微小差异；兼容只在内存中缩短已核实的旧租约，不扩大预算或抹去记录。

## 2026-10-24 分享面板与换片输入修复

继续复用现有 ChatBrowser v2 身份绑定、VideoForwarder、AutonomousShare、发送收据、浏览器互斥和 Playwright 真实输入，不增加依赖。分享面板适配当前已渲染行固定位置的自有用户数据：以 sec_uid 对照现有许可身份，再用同一用户对象的 uid 核对该行发送按钮。昵称和头像只供显示，不用于替代稳定身份。未知结构保持拒绝发送；不遍历全局状态或调用未公开接口。

换片沿用真实几何、中心命中与一次鼠标输入，在等待和输入到达时再次核对原作品及验证遮挡。分享处理中状态通过发送锁与 operationId 精确对应，未确认记录继续要求人工核对。旧收据未保存的失败细节不补造；新失败只保存阶段、代码和去敏说明。当前网页实测与合成回归分别记录，群聊实机验证仍取决于真实许可群会话。
