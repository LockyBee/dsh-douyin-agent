# 1.4.3 自检与按报告修复

复用已有诊断模块、专用浏览器归属检查、CDP窗口回读、静默控制、DSH工具注册和设置通信载体，没有新增运行依赖。报告由受控检查生成，不采集网页正文、人格、联系人、作品链接、Key、Cookie或本机完整路径。

在插件“设置 → 刷抖音 → 自检与用量”或软件“自检与用量”点击“一键自检”。报告逐项显示状态、错误码和处理步骤；可展开“查看或复制诊断报告”交给维护者。缺少Edge、宿主设置接口不可用、专用浏览器未连接是不同问题，分别给出建议。浏览器未打开时不自动启动或播放；没有媒体时不把媒体检查记为通过。

本版增加真实窗口是否最小化、作品媒体是否静音、可见登录与验证码提示、允许时段自动启动开关，以及好友服务是否启动和有无待核对发送的检查。窗口最小化不等于后台持续播放已验证；没有检测到登录提示也不代表账号权限已验证。自检不花费模型Token，不向真实好友发测试消息。

发现静默已经开启但窗口仍显示或作品未静音时，报告提供“修复：重新应用静默设置”。仅重新连接已经存在且归属核对通过的专用浏览器，重新应用原设置。全屏、混有非受管标签、登录验证时不自动隐藏窗口。修复前重查现场，修复后重新回读窗口与媒体，返回 repaired（已确认）、skipped（状态变化，未执行）或 unresolved（未确认修复）。旧报告不能重复执行，报告五分钟内有效；不自动循环重试。

用户让DSH排查时，大肥鱼可调用 `douyin_diagnostics`，再按报告的 `repairableActions`、`reportId` 调用 `douyin_diagnostics_repair`。诊断工具不依赖设置页的HTTP通信，所以设置页不能打开但工具已注册时仍可排查。若整个插件或工具没有加载，无法通过这些工具自修，需要按安装说明检查插件加载。

自动修复不会启动观看、私信或问候服务，不会发送、清空记忆、删除登录资料、修改Key或许可、重置预算或清理发送待核对记录。缺少依赖、文件权限、损坏记录、登录验证码或宿主版本接口不兼容时提供人工步骤；未知源码缺陷需要维护者修复和版本更新。本次没有声称能自动修好所有用户的环境。
