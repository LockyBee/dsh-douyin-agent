# 1.5 初期开发记录

以下记录 1.5.0-beta.1 首批变更与当时的验收范围。正式版本见[更新记录](../CHANGELOG.md)。

首批改动：

- 自主观看可提议点赞或收藏。插件和软件分别提供两个自动保存的许可开关，默认关闭。宿主绑定实际观察的作品和观看轮次，模型不能自行打开开关或指定其他作品。
- 已有点赞收藏状态只回读；不会执行取消。每个作品的每类操作只处理一次，不明结果保留回执、暂停后续互动，观看仍可继续。
- 评论生成先判断是否有具体内容可说。与本账号近 24 小时已发评论高度相似时跳过，不增加发布次数，不中断观看；原有用户设置及未确认评论收据保留。
- 插件直接依赖已在运行包使用的 playwright-core 与 YAML，保留版本锁和许可证，移除未直接调用的 CLI/MCP 依赖入口。软件的体积优化另做分析。

验收范围：服务层、完整观看循环、设置 HTTP、DSH 设置传输、合成浏览器页面和软件界面构建。合成页面测试不代表真实抖音操作成功。

真实平台仍待核对：点赞收藏控件当前结构、本人状态及服务端回执。当前适配只接受同作品内明确的按钮标签与选中状态；无法证明未选中时不点击，不用图标颜色推断。本人链接仅为别名、按钮没有明确状态等页面尚未接通。流水长期归档和已确认互动参与兴趣学习也须补齐后再进入正式验收。

后续依次处理特殊消息、图文与直播，完全后台模式，内存与体积；Mac 最后。仅聊天/仅刷视频版本保留为探索项。更新视频还需说明此前观看策略、消费变化和记忆优化，并核对实际数据。
