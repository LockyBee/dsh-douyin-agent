# DSH 原生抖音插件 1.4.6

日常入口是 DSH“设置 → 刷抖音”，通过分类设置操作，不要求在聊天中输入工具名。插件使用 DSH 已配置的主模型；独立软件使用自己的 API Key，两版共用本机人格、兴趣、每日用量、许可名单与收据。

## 安装与更新

DSH Desktop 在“应用 → 桌面插件”填写 `dsh-douyin-browser-local@1.4.6`，安装或更新后完全退出并重新打开同一份 DSH。Web profile 可执行：

```powershell
dsh plugin --profile web add dsh-douyin-browser-local@1.4.6
```

固定包及校验文件见 [1.4.6 下载页](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.6)，是否可下载以页面为准；npm、GitHub 与社区市场分别同步。需要 Windows、Microsoft Edge 和兼容 DSH，已检查 0.2.0-rc.2、0.2.1-rc.2 两代 SDK，完整允许版本以 `package.json` 的 `engines.dsh` 为准；不保证任意 0.2.x 预发布或第三方宿主。源码安装另需 Node.js 22.13+ 和本仓库依赖，不需要独立软件或 QQ 服务。

源码安装在仓库根目录先检查：

```powershell
pnpm install --frozen-lockfile
$dshInstallDirectory = 'C:\Apps\DSH Desktop' # 替换为实际安装目录
.\install-native.ps1 -DshRoot $dshInstallDirectory
```

不带 `-Install` 不改配置。确认路径正确、完全退出 DSH 后运行：

```powershell
.\install-native.ps1 -DshRoot $dshInstallDirectory -Install
```

安装器保留原 profile 副本，不删除登录、记忆或收据。标准 bundle 与既有 file URI 不应重复注册同名插件，可用的既有入口无需额外叠加一份。源码目录移动后需重新安装链接。

## 分类设置与自动保存

| 栏目 | 内容 |
| --- | --- |
| 基础设置 | DSH 提供商和模型下拉、共享人格正文 |
| 视频观看 | 总允许开关、手动启动／暂停、时段、主题、静默及折叠的每日额度 |
| 好友互动 | 统一开关、许可好友／群聊、群聊昵称、最近分享及待核对项 |
| 公开评论 | 独立开关、每日和每次观看的尝试上限 |
| 音频与密钥 | 音频开关、后端及 MiMo／MiniMax 独立密码框 |
| 观看日报 | 生成、选择日期与读取 |
| 自检与用量 | 诊断、限定修复、报告与实际模型用量 |

普通设置自动保存：文本离开输入框后提交，开关、下拉和快捷选择修改后提交。页面显示正在保存、已生效或失败原因；失败保留草稿，轮询不覆盖未保存输入。运行中修改名单会先协调暂停回复，再保存和核对。

先在 DSH 的“模型”页配置提供商，再在本插件选择支持图片的模型，这里不重复填写主模型 Key。人格正文与软件共用，离开输入框后保存；版本冲突时保留草稿，核对后载入最新人格。人格决定称呼、情绪与表达习惯，不改变许可或现实承诺；兴趣按实际观看证据另行更新。

## 视频观看

点击“打开抖音”，由本人在专用 Edge 登录或完成验证码。准备入口不自动开始观看；已有自主观看时只显示既有页，不额外开一条循环。

开启“允许自动观看”后，DSH 保持运行时按允许时段和每日额度自动观看，无需先开启新轮次。“开始自主观看／暂停观看”与总允许开关共用设置。时段外等待，下次允许时段可继续；日额度耗尽等待上海日期次日。登录、验证或运行异常需按停止原因处理后再开启，不会每次轮询盲目重试。

每日时段按 `Asia/Shanghai` 计算，支持 1–16 个 `HH:MM-HH:MM` 窗口、`23:00-01:00` 跨午夜及 `00:00-24:00` 全天。页面提供谷时段、全天、晚间及周末全天快捷选择；快捷选择只填写时段，不保证供应商价格或折扣。

“高级选项”内设置每日观看分钟数和每日观看模型请求数，初始默认 10 分钟、30 次，均可为正整数或不限；已有配置沿用迁移值。实际活动观看时间和请求在两版间共享，按上海自然日累计。暂停、重启、重新开启或改设置不清空当天记录；评论生成也占观看请求数，好友私信请求不占观看额度。

“观看主题”可选择推荐流或围绕填写的主题挑片。少量采样不能代表看完整条或听懂声音，看到主题不等于喜欢。停止原因直接显示在视频设置中。

静默观看持续静音，核实窗口全为受管页面且无登录验证后尝试最小化；不能核实时显示未隐藏原因。关闭静默不抢焦点，可点“打开抖音”显示。它仍是有窗口 Edge，不是 headless，不能保证网站在最小化后持续播放。

## 好友互动与评论

“允许好友互动”总开关默认开启，统一管理新消息回复和观看中的自主分享。读取当前会话列表后，由本人核对并勾选许可好友或群聊；未选会话不会外发。人数、回复模型请求数及分享次数没有业务上限，模型调用仍会消耗额度。旧自动问候／续火花已移除。

许可按平台稳定账号／会话标识和个人、群聊类型绑定，昵称、头像只供显示。同账号改名不应丢失许可，同名不同账号不能继承许可。显示“身份信息不足”时不可新选；旧弱身份记录需按实际平台标识重新核对，不得伪造关注或编辑状态文件放行。

许可群聊仅在被 @ 或叫到设定响应昵称时回复。新消息提示和 2 秒轮询共同检查，实际回复还需页面读取、模型生成与收据核对。模型只读当前许可会话相关消息、显示名和手编人格，不带其他会话或 QQ 历史；直接发送正文，不加固定“自动回复”标签。

首次启动建立旧消息基线；主动关闭后不会补发旧消息。短暂设置维护仅恢复证据完整、尚未发送的待答项，身份不明、已有人回复、旧资格不足或发送未确认时保留人工处理。顶部状态栏显示在线、观看中、准备中或需要处理，总开关开启不等于服务已经就绪。

自主分享选择当前实际观察作品和现有许可收件人，经官方面板发送作品卡片，不改发文字链接、人格或私人记忆。面板收件人与按钮均核对稳定身份，最终输入时再次核对。同作品同收件人已有确定处理记录时跳过该动作并继续观看；未确认记录仍暂停等待人工核对，不自动重发。最近分享显示已保存的失败阶段与原因。

公开评论独立开关默认关闭；默认每日 3 次、每次观看 1 次，可分别设 1–20 和 1–3。正文另用一次只含当前作品实际画面、标题和作者的请求生成，不提供人格原文、私信、QQ 或联系人资料；最多 200 字，不含 @、链接或私人信息。同作品去重，预留计入尝试，失败或人工核对不退次数。缺少可核评论输入区或按钮时停止，不猜坐标或宣称成功。

发送结果不确定时，先在抖音核对原收据，再记录结果；核对不会重发。最终短输入持锁期间，关闭或修改可能返回忙，需以成功回读为准。

## 音频与密钥

音频默认关闭，刷视频无需 MiMo／MiniMax Key。本地 Whisper 转写对白需要可用的运行环境和模型；云端视频音频后端才需要相应凭据。

在“音频与密钥”分别填写 MiMo API Key 或 MiniMax API Key，离开密码框后通过专用凭据接口保存。留空沿用原值，不回显。两版共用本机媒体 `.env` 明文文件，进程环境变量优先时页面显示来源。保存 Key 不开启音频、不下载模型、不发云端请求；后端和开关另行选择。不要把 Key 放入人格、聊天、普通设置或公开报告。

原生小表情读取平台名称；无名称时保留未知信息。普通图片、独立贴纸和分享卡片仅采集许可会话中指定消息的画面，封面不等于整条视频。

收到的语音仅在启用音频、选择 `local-whisper` 且本地可用时转写，限指定单条消息，最长 120 秒、最大 25 MiB。临时文件用后清理，转写只用于当前会话，不写全局兴趣。有效音轨没有识别到对白时可自然追问，不编造说话或环境声；音频关闭、后端不可用或转写失败时暂停该联系人。群聊仍先满足 @／昵称触发，纯语音不能绕过。

## 共享文件与日报

位置记录默认在 `%USERPROFILE%/.dsh/douyin-browser/runtime-location.json`。保留既有登记目录，新机器默认共同记忆在 `%USERPROFILE%/.dsh/douyin-browser/memory`；以页面回读为准，不另复制一套或删配置修路径。

| 位置 | 内容 |
| --- | --- |
| `memoryDir/persona/role-card.md` | 手编人格及受管生成区 |
| `memoryDir/persona/state.json` | 作品观察、观看与兴趣依据 |
| `memoryDir/reports/videos/YYYY-MM-DD.md` | 上海日期的视频日报 |
| `memoryDbPath` | 共享 SQLite 记忆库 |
| `stateDir/video-policy.json`、`video-usage.json`、`watch-budget.json` | 观看设置、每日时长及请求账本 |
| `stateDir/friend-interactions-policy.json`、`chat-*`、`share-*` | 互动开关、许可、协调与收据 |

日报仅汇总留存视频的标题、作者、规范链接、可核进度和互动，注明覆盖范围；不读人格正文、私信或 QQ，不调用模型。可手动生成，观看结束后也会尝试生成；相同事实保持幂等，手改报告冲突时不覆盖。

## 自检、通信与验收边界

遇到“没有可用的同源设置服务”等错误，确认插件和正在使用的 DSH 版本，完全退出重开后运行一键自检。常用 WebServer、Connection Fetch 和宿主 RPC 路由已适配，不承诺任意第三方宿主。不要靠重填 Key、删除记忆或登录目录处理通信问题。背景见[设置通信记录](verification/settings-compatibility-20261023.md)。

自检区分浏览器、模型、设置承载、调度及互动故障，提供错误码和步骤；仅执行报告列出的限定修复。当前自动修复主要重新应用已授权静默设置，不会自动登录、绕验证码、改许可、清锁或重发。

本机受控卡片流程与隔离稳定身份、最终输入、每日用量及自动保存测试分别留有记录；合成通过不等于平台联调通过。真实群聊、长期运行及本轮更新后的新私信回复尚待单独实测；真实公开评论和 MiMo／MiniMax 云端也不能视为已验收。后台打开浏览器仍有偶发超时，尚未根治。历史记录见 [verification/](verification/) 和 [软件验证说明](../desktop/VERIFICATION.md)，保留各自日期和版本。

兼容工具仅供内部及维护，旧轮次、问候等接口不能绕过当前许可或恢复已移除功能。GPT 与 DSH 协作使用上级 `bridge.ps1`，遵守轮数与尝试预算。复用来源及许可证见 [reuse.md](reuse.md)、[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
