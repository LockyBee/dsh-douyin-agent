# 1.4.4 更新说明

插件与独立软件同步三项修正，保留1.4.3的功能和原设置。

## 单轮分钟数

选择“不限单轮时长”后，分钟框显示“不限”占位，仍可直接输入。填写数字会切回限时草稿；插件点击“保存视频时间”，软件点击“保存时间设置”后生效。轮询不会覆盖未保存输入，输入本身不会更改后台策略。有限分钟数范围仍为1至1,000,000。

## 自主观看停止原因

视频观看设置直接显示后台记录的上次停止原因，便于区分到时、请求预算、模型或页面异常。没有记录时不凭空补出原因。显示原因不会重试、加时或清空预算，也不代表截图里的长视频问题已经复现或修复。

## 分享名单在哪里

- 插件：“设置 → 刷抖音 → 好友互动 → 许可好友与自动回复”，读取已关注联系人，勾选后保存许可好友。
- 软件：“业务设置 → 好友互动 → 好友私信”，读取联系人，勾选后保存许可名单。

自主分享与私信设置共用许可名单，不必启动自动回复；自主分享仍须单独保存总许可和次数上限，保存名单本身不会发送。沿用最多两位已核对关注的个人联系人。

## 安装与验证

DSH Desktop的npm包输入框填写`dsh-douyin-browser-local@1.4.4`，更新后完全退出并重开DSH。独立软件使用[GitHub Release](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.4)中的Windows x64 EXE，保留原Key、人格、记忆和登录资料。

本版专项与实际便携包检查见[验证记录](verification/ui-feedback-20261023.md)。测试和本机效果不能替代第三方电脑、真实模型请求或真人消息的完整联调。
