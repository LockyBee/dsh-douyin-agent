# 1.4.1 本地更新

插件和独立软件共用按时段自动启动的设置与回执。软件新增检查更新，修复EXE、快捷方式和左上角图标，设置导航统一放在“业务设置”的七个栏目中。当前为本地候选版，尚未发布npm或GitHub Release。

## 按时段自动开始

在“视频观看”保存允许时段与单轮时长，再勾选“每个允许时段自动开始一轮”，设置模型请求上限并保存自动启动。默认关闭；单独保存时间段不会开启。

DSH或独立软件至少一个入口需保持运行。调度每5秒检查一次，在允许时段内自动开始一轮，沿用原时钟、模型预算、登录与验证要求。进入当前时段后才开启开关，也会尝试本时段的一轮。时长、时段结束或请求预算先到便停；选择不限单轮时长时仍受时段结束与请求预算约束。

两个入口共享一份占位记录；同一时段最多自动启动一次。全天按北京时间每天一轮，跨午夜时段保持同一轮，重叠时段合并。同一时段手动停止、软件重启、启动失败均不自动补开。失败原因需人工处理；手动开始仍是独立操作。关闭自动启动只阻止后续启动，不结束正在观看的一轮。

调度记录在共用stateDir的watch-schedule-policy.json和watch-schedule-runs.json，不能通过删除记录来处理登录或模型错误。记录损坏、残留调度锁时保留原文件并停止自动启动。

## 好友互动状态

“好友互动”顶部区分许可和真实运行状态：新私信回复需要启动回复服务，自动问候需要保存许可并启动调度，自主分享和评论需要自主观看运行。界面显示暂停好友数量，联系人身份核对失败时提示重新核对名单。不会为了检查状态发送消息。

身份不符、群聊、发送结果不确定、预算耗尽等仍会暂停。服务运行不等于消息已送达；暂停联系人需要按下方状态在抖音核对，不自动绕过或重发。

## 软件检查更新

左下角“检查更新”读取固定仓库LockyBee/dsh-douyin-agent的最新正式GitHub Release。发现更高版本后可下载，长度、EXE文件头和SHA256均通过后，才显示“更新并重启”。更新前须停止正在运行的任务和服务。新版打开后自动观看仍按已经保存的调度许可执行；私信与问候服务需本人重新启动。

没有正式Release时明确显示“仓库暂未发布可下载的软件版本”；仅发布npm包不会触发软件更新。发行者须在正式Release中同时上传以下两份文件：

~~~text
Dafeiyu-Douyin-API-X.Y.Z-win-x64.exe
Dafeiyu-Douyin-API-X.Y.Z-win-x64.exe.sha256
~~~

标签须为vX.Y.Z或X.Y.Z，不接收预发布、降级或其他站点的可执行文件。构建后的verify-packaged-api.mjs会生成对应sha256。下载放在本机软件用户目录的updates中，重启助手和Node也先复制到持久目录，避免便携版退出清理解压目录时丢失。桌面“大肥鱼抖音助手”快捷方式指向新包；记忆、人格、登录资料和模型设置保留。旧下载不会由自动更新擅自清理。

## 复用与验证边界

实施前检查了既有VideoLimits、AutonomousWatch、Electron打包配置、官方组件和用户指定的启动器图标。采用现有Node定时器与原自主观看流程，只补跨入口时段占位和状态展示。图标从用户指定的大肥鱼启动器资产原样复制，界面PNG无损提取自同一ICO；EXE资源写入沿用electron-builder已缓存的resedit，不新增运行依赖。

更新器复用Node HTTPS和Electron窄IPC，补固定发布仓库、下载校验及重启助手；本软件是便携包，采用精确EXE加SHA256的流程，不引入需要另一套安装器元数据的electron-updater。SHA256用于文件完整性核对，软件包未做代码签名。

回归、隔离软件包、当前本机状态和真实模型/真人发送分别记录。合成测试不代表抖音平台已确认送达，也不代表未运行的服务会自行发消息。
