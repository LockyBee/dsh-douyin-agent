# 1.4.0 使用说明

本版同时更新 DSH 插件和独立 Windows 软件。本机更新不代表已经发布到 npm 或插件市场。

软件默认打开设置页，与插件共用同一份七栏目目录，并使用 DSH 原生组件和主题变量。模型 Key 由软件自己的设置保存；对话保留在单独入口，对话中的快捷控制仍可手动展开。

## 一键自检与用量

插件：打开 DSH 设置 → 刷抖音 → 自检与用量。软件：打开左侧“自检与用量”。点击“一键自检”，查看设置通信、Node.js 与 SQLite、Edge、共享记忆和状态目录、模型配置、观看设置、运行锁与用量记录。

自检只在内存中试用 SQLite，并在状态、记忆目录中创建后删除临时探针。它不打开抖音，不调用付费模型，不验证云端 Key 或抖音登录，不改动已有设置，也不自动删除运行锁。失败项会给出处理提示。

用量看板显示今日和最近30个有记录日期的模型响应数、输入、输出、总 Token、缓存命中及用量未知的响应数，并按插件/软件、模型和用途汇总。两版使用同一份本机记录，重启后仍可查看。缓存命中是输入的一部分，不另加到总量。

记录从本版开始，不回填历史；DSH 普通会话、云端音频和失败且未返回用量的请求不计入。没有接口报告值的响应标为“未知”，不能当作零消耗。这里只统计调用量，不是服务商账单。

## 主题观看

插件：设置 → 刷抖音 → 视频观看 → 观看主题。软件：业务设置 → 视频观看 → 主题观看。

选择“自主挑选推荐”或“围绕指定主题观看”，填写主题和排除关键词，点击“保存观看主题”。主题和排除词各最多20项，每项最多100字，按行或逗号分隔。保存前先停止自主观看，下一次启动时生效。

主题模式先搜索首个主题，打开页面实际返回且可核实的作品，再由大肥鱼按主题、人格及实际观察继续选择搜索、停留或跳过。没有可靠搜索结果时会停止。排除词按作品标题匹配，不保证过滤视频里未识别的内容。它不会改变分享、私信和评论权限。

## 时长、预算与谷时段

- 单轮分钟数可填1至1,000,000，或勾选“不限单轮时长”。每日允许时段继续生效，离开时段会停止；全天且不限单轮时长时，没有时长截止，仍可手动停止。
- 自主观看本轮请求可填1至10,000，默认30；每日最多20,000次。停止再启动不会清空本轮已用请求。保存更长时长不会给旧轮次加时，需要亲自开始新一轮。
- 软件手动任务最多可设10,000步、10,000次工具调用、604,800秒，默认仍为20步、20次、180秒。对单次响应、图像采样、外发消息和评论的限制保留。
- “谷时段（DeepSeek）”填入工作日00:00–09:00、12:00–14:00、18:00–24:00，勾选周末全天；也有“全天”和“晚间20–22点”快捷按钮。填入后点击保存才生效，不会预约启动。

谷时段按2026-10-23核对的[DeepSeek官方价格规则](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)设置。法定节假日也属于空闲时段，但本版不内置节假日日历，需手动改为全天。其他模型服务商优惠时段以其官方规则为准。

旧用户的时间设置、人格记忆、许可名单、Key与登录目录不会因升级自动放宽或重置。
