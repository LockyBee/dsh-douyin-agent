# 1.4.6 更新说明

插件和独立软件使用同一套人格、兴趣、许可名单和每日观看账本。软件另外提供任务对话，可使用自己的 API Key，无需运行 DSH。

本次主要修复个人私信的发出确认与已读不回、群聊旧历史补载导致的回复失效；加强多种消息和共享记忆输入，减少手工待答处理。群内新分享视频会在原观看时段和预算内排队观察，由模型决定继续或停止；单独分享不会自动往群里发文字。

视频采样接入分镜拼图，降低同批图片数量，并可精读指定格。多对象分享串行处理，单个对象的确定未发送故障不拖停观看。视频和消息尽量共用两个受管标签，改进连接、缓存与准备失败后的资源回收；用户自己打开的标签和未发送草稿不会被强行关闭。

## 更新

DSH Desktop 在“应用 → 桌面插件”安装 `dsh-douyin-browser-local@1.4.6`，更新后完全退出并重新打开 DSH。Web profile 使用：

```powershell
dsh plugin --profile web add dsh-douyin-browser-local@1.4.6
```

独立软件在“检查更新”获取正式版，或从 [1.4.6 Release](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.6) 下载 Windows 便携包。正常退出旧版后再打开新版，原记忆、Key、登录资料、许可与每日用量保留。

普通许可聊天全天运行；群文字仅在被 @ 或叫到响应昵称时回复。观看、分享和公开评论继续遵守原授权，公开评论默认关闭。平台确认之前不把发送记作成功，也不因更新重复发送。
