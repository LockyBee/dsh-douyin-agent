# 独立软件与本机 API 1.4.6

独立 Windows 软件使用自己的 API Key，保留任务对话；不需要安装或启动 DSH、QQ 服务及 Node.js。软件和插件共用分类设置、人格、兴趣、每日观看用量及许可名单，日常界面见 [软件说明](../desktop/README.md)；插件入口见 [plugin.md](plugin.md)。固定包见 [1.4.6 下载页](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.6)，是否可下载以页面为准。

## 软件配置

在模型设置中填写支持图片的模型及兼容接口地址，在主模型密码框填写自己的 API Key。离开输入框后通过桌面 IPC 保存，不进入普通本机 HTTP 请求，也不回显。Key 默认仅供本次运行；选择记住时使用系统加密，无法加密时只在内存使用并提示。清除入口只处理本软件保存的主模型 Key，不改 DSH 或 QQ 配置。

普通业务设置自动保存：文本离开输入框、开关或下拉修改后提交，以回读状态为准。失败会保留草稿，轮询不覆盖未保存输入。音频 Key 保留独立密码框和安全接口，见下文。

## 观看、对话与每日额度

“视频观看”开启“允许自动观看”后，应用保持运行即可按允许时段自动挑片，不用先手动开始新轮次。保留“开始自主观看／暂停观看”，与总允许开关共用设置。时段外等待；每日额度耗尽后等上海日期次日。登录、验证码或运行异常需处理后重新开启，不会无限重试。

按 `Asia/Shanghai` 设置 1–16 个每日窗口，每行 `HH:MM-HH:MM`，支持 `23:00-01:00` 跨午夜和 `00:00-24:00` 全天。可用谷时段、全天、晚间及周末全天快捷选择；快捷选择只填时段，不保证供应商折扣。“高级选项”内可设每日观看分钟数、每日观看模型请求数，初始默认 10 分钟、30 次，均支持正整数或不限。已有安装沿用迁移值。

每日账本按实际活动观看及请求累计，两版共享。暂停、重启、修改配置或重新开启不会清空当天记录；跨午夜分日计数。评论生成也占观看模型请求数，好友私信请求不占观看额度。页面实时显示已用秒数、请求数和进行中状态；token 仅计实际平台已报告值，未报告不当作零，也不据此推算费用。

“观看主题”可以选择推荐流或围绕主题搜索。兴趣依据真实进度、观看比例、停留、跳过和已确认互动更新，看到主题不等于喜欢。两版同时只运行一条自主观看。

软件的任务对话用于手动下达搜索、观察、总结等任务。手动任务默认 20 步、20 次工具调用、180 秒，可在任务预算中调整；当前范围为 1–10000 步、1–10000 次、10–604800 秒。它与每日观看额度、时段限制分别生效，不自动新建任务绕过限制。普通任务模型没有裸私信、直接评论、点赞、关注或购买工具。

静默开启后持续静音，核对受管窗口归属后尝试最小化，不改用户系统音量；关闭不抢焦点，可用“打开抖音”显示。仍是有窗口 Edge，最小化后是否继续播放以实际网站进度为准。

## 好友互动

“业务设置 → 好友互动”只有一个总允许开关，默认开启。读取当前会话，由本人勾选许可好友或群聊后自动保存；模型和名单就绪后自动准备回复，观看中可自主分享。不设人数、回复模型请求或分享次数的业务上限，模型费用仍由使用者承担。自动问候／续火花已移除。

许可依平台稳定账号／会话标识和类型核对，不依赖昵称或头像匹配。同稳定账号改名仍保留许可，同名不同账号不能继承。身份不足的行不可新选；旧弱身份记录需重新核对。群聊仅在被 @ 或叫到设定响应昵称时回复，普通群消息不请求模型。

新消息提示及 2 秒轮询共同检查。回复采用共用手编人格的称呼、情绪和表达习惯，只读当前许可会话相关消息及显示名，不带 QQ、其他会话或观看记录，不加固定“自动回复”前缀。页面读取、模型生成和收据核对均会占用时间，不保证零延迟。

首次启动建立旧消息基线；主动关闭后不会补发旧消息。设置维护只恢复证据完整、尚未发送的待答项，旧资格不足、身份不明或已有人工回复时留待核对。发送结果不明保留收据并暂停，不自动重发。未知附件或采集失败可进入待人工处理，不把它假称为已读懂。

自主分享从当前实际观察作品中选取内容及现有许可收件人，走官方面板发送原生作品卡片，不改发文字链接或私密记忆。面板行、按钮和最终输入都核对稳定身份。同作品同会话已有确定终态则跳过该动作继续观看；未确认记录不能当作已处理，也不能自动重试。最近分享显示具体失败阶段与原因。旧明确选人、选片的手动转发接口仅作兼容，不向普通模型开放可信发送权限。

顶部状态栏按真实运行、模型、名单和待处理项显示在线、观看中、准备中或需要处理。总开关开启不代表全部就绪；观看不会关闭好友新消息检查。

## 评论、音频与日报

公开评论独立开关默认关闭，默认每日 3 次、每次观看 1 次，可分别设 1–20 和 1–3。只评论当前实际观察作品，正文另用一次公开内容请求生成，不读人格原文、私信、QQ 或联系人资料，最多 200 字，不含 @、链接或私人数据。同作品去重，预留计入尝试，失败及人工核对不退次数。无法识别输入区或按钮时停止，不猜坐标或宣称已发布。

音频默认关闭，基本观看无需音频 Key。本地 Whisper 需要另备运行环境与模型；MiMo、MiniMax 是视频音频的可选云端后端。软件在“业务设置 → 音频与密钥”填写对应密码框，离开后通过桌面 IPC 保存；插件通过 DSH 专用凭据接口保存。留空沿用、不回显，两版共用本机明文媒体 `.env`，不同于主模型 Key 的可选系统加密。保存 Key 不启用音频、不切后端、不下载模型或发云请求；普通 HTTP 页面不接收 Key。

收到的语音仅接入已启用且可用的 `local-whisper`，限当前许可会话指定单条消息，最长 120 秒、最大 25 MiB。不录麦克风或系统声音，临时文件用后清理，转写仅供当前会话，不写兴趣。有效音轨未识别到对白时可追问，不编造声音内容；关闭音频、后端不可用或故障时暂停该联系人。群聊仍先满足 @／昵称触发。原生表情读取名称，图片、贴纸和卡片仅采集指定消息，封面不能当作看完整条。

音频来源与许可证见 [media/README.md](../media/README.md)、[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。MiMo／MiniMax 云端未完成本轮真实联调。

日报从本机留存的视频事实生成 `memoryDir/reports/videos/YYYY-MM-DD.md`，列出标题、作者、规范链接、可核进度和互动及覆盖范围；不读人格正文、私信或 QQ，不调用模型。可手动生成，观看结束也会尝试生成；重复事实保持幂等，手改稿冲突时不覆盖。

## 源码本机 API

本节供维护和开发使用。便携软件直接运行 EXE，旧 HTTP 控制台不是桌面凭据填写入口。源码运行需 Node.js 22.13+、已安装依赖与 Microsoft Edge：

```powershell
pnpm install --frozen-lockfile
.\start-api.ps1
```

默认监听 `http://127.0.0.1:3218`，也可使用 `start-api.cmd` 或 `node app.mjs`。主模型配置从进程或本机配置读取；不要将 Key 放入命令参数、网页或文档。需要改端口或模型时可在启动前设置 `DOUYIN_API_PORT`、`DOUYIN_MODEL`。旧源码配置支持受限读取既有 QQ 项目的模型环境字段，不复制其账号文件；便携软件使用自己的桌面配置，不借用 QQ／DSH 凭据。

服务只监听本机，校验 Host、Origin 与当前会话令牌，不应代理到公网。以下写入接口需要本机认证；不得向普通任务模型开放任意发送。

| 功能 | 接口 |
| --- | --- |
| 观看时段与每日额度 | `GET /api/video/status`；`POST /api/video/policy` 接收 `windows`、`weekendWindows`、`dailyMinutes`、`dailyRequests`（额度为正整数或 `null`） |
| 总观看许可 | `GET /api/watch/schedule`；`POST /api/watch/schedule` 接收 `{enabled:boolean}`，启动／暂停按钮共用此设置 |
| 自主观看与主题 | `/api/watch/state`、`/api/watch/start`、`/api/watch/stop`、`/api/watch/options`；旧 start/end 仅内部兼容，不重置每日账本 |
| 好友互动 | `GET /api/interactions/state`；`POST /api/interactions/configure` 接收 `{enabled:boolean}`；`/api/chat/contacts`、`/api/chat/configure` 维护许可；`/api/chat/resolve` 记录人工核对 |
| 分享记录 | `/api/share/state`、`/api/share/resolve`；旧 share/configure 兼容总互动开关，不另设次数上限 |
| 公开评论 | `/api/comments/state`、`/api/comments/configure`、`/api/comments/resolve` |
| 音频设置 | `/api/media/state`、`/api/media/configure`；普通 HTTP 不接收密钥 |
| 日报 | `/api/reports/state`、`/api/reports/read?date=YYYY-MM-DD`、`/api/reports/generate` |
| 自检与用量 | `POST /api/diagnostics`、`/api/diagnostics/repair`、`GET /api/usage` |

停止任务会取消当前模型与操作，浏览器和登录资料保留；关闭服务前先等发送完成或明确停止，不能把结束进程当成发送未发生的证据。

## 验证边界

测试、真实 API、DSH 加载及真实平台效果分别验收。稳定身份、按钮最终事件门禁、每日账本、自动保存、错误原因与未确认保护有隔离回归；本机受控卡片和真实模型人格候选另有记录。真实群聊、长期连续运行及本轮更新后的新私信自动回复尚待单独实测，不能将历史发送记录写成全链路已经通过。

后台打开浏览器仍有偶发超时，尚未根治。登录、验证码由本人完成，不保证任意第三方宿主或最小化后持续播放。真实公开评论及云端音频仍需单独核验。历史依据见 [verification/](verification/)、[desktop/VERIFICATION.md](../desktop/VERIFICATION.md)，各记录仅覆盖对应版本和日期。
