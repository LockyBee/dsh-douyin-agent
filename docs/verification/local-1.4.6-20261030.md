# 1.4.6 验证范围（2026-10-30）

本次正式版沿用本机已核验的 beta.13 功能源码，重新构建正式版本号的界面、Windows 便携包和 npm 包。不会通过更名旧 EXE 生成正式包。发布前检查相对导入、许可证、包白名单及敏感文件排除，并在隔离目录安装和运行打包后台。

## 已有证据

- 发布整理前的领域回归共 1344 项：1337 通过、7 项可选跳过、0 失败。此前单列的浏览器后台焦点测试本次单独执行，3 项全部通过。正式包的最终回归结果在发布记录中补充。
- 本机已确认一次许可个人私信的补答及平台发送回执，且没有重复发送；检查过两入口的消息就绪、稳定身份和实际视频时间推进。这不能替代全部账号、消息形式与群聊组合的实测。
- 稳定身份、消息资格、发出确认水位、共享记忆筛选、群历史补载、分镜、多对象分享、视频自主继续及资源释放有隔离用例。测试成功不等于真实平台发出或看完整片。
- 旧构建曾完成两小时暂停／聊天轮询内存记录：浏览器私有内存峰值约 2.60 GiB，包含辅助进程约 2.74 GiB，上下文数量未持续增长。该结果只适用于当时构建和暂停负载，不是本次正式包连续播放通过。

## 尚未完成

- 推荐流仍可能换片失败并停止；不能宣称所有观看中断问题已修复。
- 当前正式包尚无连续两小时实际播放、长期无人值守及始终低于 2 GB 的验证结论。
- DSH 0.2.1-rc.3 的“思考可见、正文不显示”反馈在干净环境未复现，根因仍待定位。
- 真实公开评论尚缺明确的新评论标识与同文回读，不能判定发布通过；默认保持关闭。
- 长视频多批次实际观察、真实多收件人分享和所有媒体组合的覆盖仍不完整。少量真实画面采样不等于看完，也不代表读到音轨。
- 原生语音气泡暂不发送；文件、位置、直播等部分卡片只识别类型和可见资料。
- 当前发布针对 Windows x64；Mac 问题不在本次完成范围内。
