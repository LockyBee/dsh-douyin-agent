# 1.3.2 设置通信兼容修复

## 反馈与原因

用户提供的多张私信和设置页截图均显示：1.3.1 设置页可加载，但报“当前 DSH 没有可用的同源设置服务，请使用支持 WebServer 的原生宿主”，模型选择、打开抖音等操作不可用。

已对照源码定位三处问题：

1. 这句报错由前端在发请求前抛出。1.3.1 仅识别本机 HTTP 和旧 Fetch 桥，常用桌面协议、HTTPS、RPC 载体会被误判；报错不能证明宿主没有 WebServer。此前仅补 dsh-app 协议不足以覆盖这些入口。
2. 后台只向 WebServer 注册设置路由。使用 Connection Fetch 载体的宿主即使放开前端检查，也可能没有对应路由。
3. 所有按钮共用未就绪禁用条件，连“刷新插件状态”也被禁用，无法手动恢复；恢复读取后旧错误还可能留在页面。

截图中模型下拉框为空，不能单独证明使用者没配置模型：状态读取失败时，页面同样拿不到模型目录。

公开视频 https://www.bilibili.com/video/BV1pHJ86uEWd/ 的公开接口显示 187 条评论计数，本轮实际只返回 4 条独立顶层评论，未返回这些错误反馈；网页读取超时。不能声称已读完整评论区。本轮依据用户提供截图和源码复现，不保留评论者的身份或私信正文。

## 修复方式与复用

复用 DSH 现有的客户端 Connection、Fetch 及宿主认证，实现窄设置通道，不新建端口，不引入依赖，不要求安装独立软件。官方契约来源：

- https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/connection/src/rpc.ts
- https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md

保留旧 HTTP 入口；识别本机 HTTPS、dsh://app、dsh-app://app 和已有 Fetch 桥，无法直接 Fetch 的页面可使用注入的宿主 RPC。后台同时注册 Connection 精确路由与兼容入口，复用相同业务处理器和令牌。独立 RPC 入口经 Connection 的宿主认证后才派发，并限制接口、输入大小与可写操作。未知来源、非所有者与无令牌写入仍拒绝，失败不自动切通道重放。

只在界面状态读取成功后启用业务按钮；刷新不再依赖就绪状态，恢复后清除旧连接错误。

## 验证范围

- 实际安装的 DSH 0.2.0-rc.2 Connection/WebServer SDK：无 WebServer 时经共享 Fetch 读取和保存；有 WebServer 时经认证 RPC 完整往返；无宿主认证、缺少写令牌、跨源、非所有者、未知接口、过长输入、预先取消和卸载行为。
- 从 npm 隔离安装的 0.2.1-rc.2 Connection/WebServer SDK：同一组检查 3 项通过；安装使用 ignore-scripts，不修改用户 DSH 安装或 profile。
- 客户端协议与界面测试：桌面协议、file 页面 RPC、HTTPS、错误不可隐式重试、断连仍可刷新及恢复后清错。
- 原有设置与原生工具目录检查继续执行；业务使用合成控制器，未打开真实抖音、调用模型或发送消息。

最终设置通信定向检查 21 项通过；0.2.1-rc.2 独立 SDK 检查 3 项通过。

首次默认高并发完整回归为 498 项：490 通过、7 跳过、1 失败。失败是既有 Node 探针测试在并发负载下超过 3 秒，单独重跑 12 项通过。受限并发回归仍为 490 通过、7 跳过、1 失败，这次是既有日报测试中的 Windows 人格卡文件替换 EPERM；日报测试单独重跑通过。没有修改这两处业务代码，也不将单独通过代替完整回归全绿。日志保存在本机 verification/v1.3.2-full-tests-20261023.log、v1.3.2-full-tests-bounded-20261023.log 及对应单独复核日志。

1.3.2 候选 tarball 已在隔离目录安装，可导入原生入口和新增设置通信模块，client.js 与 bundle 均存在；白名单包未含运行配置、密钥、浏览器资料、记忆、模型或本机验收目录。打包、安装与运行测试分别记录，没有把打包成功当成桌面实机通过。

SDK 与合成页面通过不等于反馈者机器已验收。尚未逐一检查所有第三方 DSH 分支，也未执行真人账号浏览、外发或用户桌面安装。

## 发布与升级

修复纳入版本 1.3.2，本轮准备本地候选包，不执行 npm 发布。发布后使用原安装入口更新，完全退出并重开同一份 DSH，再进入“设置 → 刷抖音”刷新状态。无需删记忆、登录目录、重填 Key 或迁移人格。
