## 反馈的证据范围

源码每轮以3秒采样进行模型决策，支持 skip；stay 每次1至10秒，不存在必须等长视频结束再决策的规则。截图中的请求取消与不能换片可能关联：循环已停止或模型请求未返回，播放器仍继续播放；也可能模型一直选择停留。需要对方版本、停止原因或决策记录才能区分，不据截图断言网络或特定模型有缺陷。

分享许可名单读取现有 chat-policy.json 的 allowlist，最多两位已核对关注的个人联系人；入口为好友互动→许可好友与自动回复→读取已关注联系人→勾选→保存许可好友，随后另行开启自主分享。这里只核对入口与逻辑，未读取真实联系人或发送。
