# 大肥鱼抖音助手独立软件 1.4.6

Windows 独立软件使用自己的 API Key 控制本机专用 Edge，并提供任务对话。不需要安装或启动 DSH、Cordis、QQ 服务及 Node.js；基础运行资源随便携包提供。它与插件共用分类设置、人格、兴趣、每日观看用量和许可名单。

固定下载入口为 [1.4.6 Release](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.6)，以页面实际附件为准，文件名 `Dafeiyu-Douyin-API-1.4.6-win-x64.exe`。先正常退出旧版再运行新版，保留记忆、登录目录及本机设置。便携包未签名，可用同名 `.sha256` 文件核对完整性。软件内“检查更新”只接受 GitHub 的正式 Release，不安装草稿或预发布包；检查成功不等于已完成下载和替换。

界面复用 DeepSeek Harness 固定 MIT 源码中的 React 组件、主题和布局，业务由本软件实现，不是 DeepSeek 官方发行版。来源见 [UPSTREAM.md](UPSTREAM.md)、[API_REUSE.md](API_REUSE.md)、[REUSE.md](REUSE.md)。

## 初次使用

1. 点击“打开抖音”，在专用 Microsoft Edge 中手动登录或完成验证。准备入口无需主模型 Key，不会自动开始观看。
2. 在模型设置中填写自己的 API Key、兼容接口地址和支持图片的模型；离开输入框后保存。
3. 进入“业务设置 → 视频观看”，选择时段，按需展开“高级选项”设置每日分钟数和模型请求数，开启“允许自动观看”。无需先手动开始新轮次，软件需保持运行。
4. 按需在“好友互动”读取会话，核对稳定身份后勾选许可好友或群聊，填写群聊响应昵称。总互动开关默认开启，模型和名单就绪后自动准备回复，观看中可自主分享。

左侧提供对话、业务设置和观看记录。人格、日报、自检与用量放在分类设置中，不另维护一套重复设置。普通业务修改自动保存，文本离开输入框、开关和下拉修改后提交；失败时草稿保留，以页面回读状态为准。

## 主模型 Key 与音频 Key

主模型 Key 从密码框通过桌面预加载层和私有 IPC 交给后台，普通 HTTP 接口不提供密钥写入或原值回读。软件不借用 DSH 或 QQ 的模型凭据。默认仅本次运行有效；选择记住时用 Electron `safeStorage` 系统加密保存到 `%APPDATA%/DafeiyuDouyinAPI/api-settings.json`。不能加密时只在内存使用并提示；保存失败时原磁盘记录可能仍在，需核对提示。

音频默认关闭，刷视频无需 MiMo／MiniMax Key。本地 Whisper 需要另备运行环境及模型；云端视频音频后端才需要对应凭据。入口是“业务设置 → 音频与密钥”的 MiMo API Key、MiniMax API Key 独立密码框，离开后通过桌面 IPC 保存，不走普通本机 HTTP，也不回显。留空沿用现有值。

音频 Key 写入与插件共用的媒体 `.env`，是本机明文文件，与主模型 Key 的可选系统加密不同。保存 Key 不启用音频、不切换后端、不下载模型、不发起云请求；再按需选择音频后端与“读取视频声音”。不要把 Key 写进人格、聊天或报告。来源和环境要求见 [media/README.md](../media/README.md)。

## 观看与任务对话

“允许自动观看”开启后，软件在允许时段和每日额度内自动挑片、停留、换片或停止，保留“开始自主观看／暂停观看”按钮，与开关共用同一设置。时段外等待，日额度耗尽等上海日期次日；登录、验证或异常停止需按页面原因处理后再开启，不会不断盲重试。

时段按北京时间计算，支持 1–16 个窗口、跨午夜和全天，提供谷时段、全天、晚间及周末全天快捷选择。快捷选择不保证供应商折扣。“高级选项”包含每日观看分钟数、每日观看模型请求数，初始默认 10 分钟、30 次，均可填正整数或选不限；旧配置沿用迁移值。

两版共享按上海自然日累计的实际活动观看与请求。暂停、重新启动或修改设置不重置当天用量；评论生成占观看请求数，私信请求不占。页面显示实时已用时长、请求与进行中状态；token 以供应商已报告值为准，未知用量保留未知。

任务对话可下达搜索、观察或总结等手动任务。其预算默认 20 步、20 次工具调用、180 秒，可设 1–10000 步、1–10000 次、10–604800 秒，独立于视频时段和每日观看额度，任一限制先到即停止，不自动创建新任务续跑。普通任务模型没有裸私信、直接评论、点赞、关注或购买工具。

“观看主题”支持推荐流和主题挑片。兴趣依据真实播放进度、观看比例与已确认行为形成，不能看到主题就算喜欢。插件和软件同一时刻只运行一条自主观看，手动视频操作受共同互斥保护。

静默开启后持续静音，核对整窗归属且无登录验证时尝试最小化；不能核实时说明原因，不改用户系统音量。关闭静默不抢焦点，可点“打开抖音”显示。浏览器仍是有窗口 Edge，不是 headless，不保证网站最小化后持续播放。

## 好友互动、评论与日报

“允许好友互动”总开关默认开启，统一控制新消息回复和观看中的自主分享；先由本人勾选许可好友／群聊，未选不会外发。不设人数、回复模型请求或分享次数的业务上限，模型调用仍会消耗额度。自动续火花／自动问候已移除。

名单依平台稳定账号／会话标识及个人、群聊类型核对，不靠昵称头像匹配。同账号改名不应失去许可，同名不同账号不会继承许可；身份不足不可新选，旧弱身份需重新核对。群聊仅在被 @ 或叫到设置昵称时回复。

好友服务与观看分开运行，观看期间仍检查新消息。回复使用手编人格、当前许可会话上下文和明确允许共享的记忆，不直接带入 QQ 或其他联系人的原始私聊，不加固定“自动回复”标签。启动建立旧消息基线，主动关闭后不补发旧消息；短暂设置维护只恢复证据完整且未发送的待答项。未知附件说明可见信息及读取边界；身份变化或未确认回执保留证据，不猜测内容或盲重发。有完整原消息、资格和未发送证据的待答项由后台自动整理。顶部状态栏按真实就绪情况显示在线、观看中、准备中或需要处理，不保证零延迟。

自主分享仅从当前实际观察作品和现有许可收件人中选择，经官方面板发原生作品卡片。面板、按钮及最终输入核对稳定身份。同作品同会话已确定处理则跳过该动作继续观看；未确认记录保留暂停。最近分享记录包含可用的失败阶段与原因，人工核对不触发重发。

公开评论独立开关默认关闭，默认每日 3 次、每次观看 1 次，可设 1–20、1–3。正文仅依据当前作品实际画面、标题与作者，最多 200 字，不提供人格原文、私信、QQ 或联系人资料，不含 @、链接或私人数据。同作品去重，预留计入尝试，失败或核对不退次数。缺少可核输入区时停止，不猜坐标或宣称成功。

日报写入 `memoryDir/reports/videos/YYYY-MM-DD.md`，只汇总实际留存作品事实、可核进度和互动及覆盖范围，不读人格正文、私信或 QQ，不调用模型。可手动生成，观看结束也会尝试；事实不变保持幂等，手改稿冲突时不覆盖。

收到的语音仅在启用音频、选择 `local-whisper` 且本地可用时转写，限指定单条许可消息，最长 120 秒、最大 25 MiB，临时文件用后清理，不录麦克风或系统声音。无可识别对白时可追问，不编声音；不可用或故障时暂停该联系人。群聊仍先满足 @／昵称触发。表情、图片和卡片只读取当前指定消息，封面不代表全片。

## 共享位置与退出

软件和插件读取 `%USERPROFILE%/.dsh/douyin-browser/runtime-location.json`。目录沿用原约定，不代表运行依赖 DSH。`memoryDir` 指向共同人格与记忆目录，`memoryDbPath` 精确保留数据库文件名，软件可直接打开记忆文件夹。

已有安装保留原登记位置，不复制、搬迁或清空数据库；新机器默认 `%USERPROFILE%/.dsh/douyin-browser/memory/shared.sqlite`。位置记录损坏或路径冲突时拒绝启动，避免生成另一套库，不应删记录绕过。

人格位于 `memoryDir/persona/role-card.md`，手编正文与受管生成区分开；`state.json` 保存实际观察及兴趣依据。人格自动保存有版本核对，冲突保留草稿；共享文件不构成向 QQ 群或公开渠道传播私密内容的授权。

关闭软件停止它拥有的后台与任务，专用 Edge 及登录资料保留。未确认的发送收据保留，退出不等于未发送；另一个入口运行状态应单独回读。遇登录和验证码由本人完成。

## 自检与验证边界

先运行“一键自检”，按报告处理浏览器、模型、设置承载、调度和互动问题。自动修复仅限报告列出的动作，不能自动登录、绕验证码、改许可、删除锁或清空记忆。错误时可复制去敏报告。

本次包含许可个人私信的真实补答及平台确认、稳定身份和播放推进核对，另有隔离回归和正式包检查。推荐流换片、正式包连续两小时实际播放及 2 GB 内存目标尚未完成验收，DSH rc.3 正文显示反馈未定位，真实公开评论发布确认仍待验。不承诺其他机器或任意宿主兼容。详见[本次验证范围](../docs/verification/local-1.4.6-20261030.md)。

## 从源码构建

构建需要 Windows x64、Node.js 24 和 pnpm，首次下载公开依赖及固定源码，缓存位于 `.cache/`。

在 `desktop` 目录准备依赖和运行资源：

```powershell
pnpm --ignore-workspace install --ignore-scripts --frozen-lockfile
node node_modules/electron/install.js
node scripts/acquire-upstream.mjs
node scripts/stage-api-runtime.mjs --prepare-node-only
```

按界面、后台、桌面入口、打包顺序运行：

```powershell
cd ui-api
pnpm --ignore-workspace install --ignore-scripts --frozen-lockfile
node build.mjs
cd ..
node scripts/stage-api-runtime.mjs
node scripts/build-api-desktop.mjs
pnpm package:dir
pnpm package:portable
node scripts/verify-packaged-api.mjs
```

最后一项使用隔离目录和隐藏窗口检查便携包，不调用真实模型或操作真实抖音。输出在 `release-api/`。运行资源不包含 DSH Host、Cordis、账号配置或个人状态；界面、后台、Electron 和 Node 的来源及许可证随分发资源保留。包校验、窗口启动和真实平台功能分别验收。
