# 大肥鱼抖音助手独立软件

1.4.4 同步修复分钟数字框、在视频观看设置显示停止原因，并说明自主分享名单的维护入口。[查看本版说明](../docs/features-1.4.4.md)或[下载 Windows 便携版及校验文件](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.4)。保留上一版的一键自检、按报告修复、用量看板、自动启动和软件检查更新。

Windows 独立桌面软件直接使用用户填写的 API Key 调用模型，控制本机专用 Edge 浏览抖音。基础运行资源随软件提供，使用时无需安装或启动 DSH、Cordis、QQ 服务及 Node.js。当前版本为 1.4.4，与插件版同步 34 项领域工具和业务模块；两种入口共用本地记忆、大肥鱼人格与兴趣。本版构建、打包和启动的实际结果见 [VERIFICATION.md](VERIFICATION.md)，旧版本记录只覆盖对应版本。

目前优先使用[插件原生设置页](../docs/plugin.md)：在 DSH“设置 → 刷抖音”内选模型、设时间、打开抖音并点击启动，不需要输入聊天指令。软件版保留任务对话，使用自己的 API Key。

左侧保留“业务设置”“对话与视频”和“自主观看记录”；人格、日报、自检与用量统一放在设置分类中。MiMo Key在“业务设置 → 音频与密钥”选择MiMo后填写。好友互动顶部显示服务实际状态，保存许可不等于服务已启动。

使用 `Dafeiyu-Douyin-API-1.4.4-win-x64.exe`。先正常退出旧版，再打开新版；保留原共享记忆、人格、登录资料和本机 API 设置。无需迁移文件夹或重新安装 DSH。便携包尚未签名，下载后可使用同名 `.sha256` 文件校验完整性。

界面复用 DeepSeek Harness 固定 MIT 源码中的 React 基础组件、主题和布局样式，任务、设置及业务状态由本软件实现。它不是 DeepSeek 官方发行版。来源及复用范围见 [UPSTREAM.md](UPSTREAM.md)、[API_REUSE.md](API_REUSE.md) 和 [REUSE.md](REUSE.md)。

## 使用与设置

需要 Windows x64 和 Microsoft Edge。首页标题栏和首次 Key 表单均有“打开抖音”按钮，不需 Key，可先打开专用窗口手动登录或验证。准备入口会暂停视频，不开始或延长计时；已有自主观看运行时只聚焦现有页，不改它的播放状态。正式浏览需手动开始轮次，或事先明确保存按时段自动启动许可。

配置模型时填写 API Key，接口地址和模型可按所用兼容服务修改。主模型密钥通过桌面预加载层交给主进程，再通过私有 IPC 交给随包 Node 后台；普通 HTTP 接口不提供密钥设置与回读。独立软件不会借用旧 DSH 或 QQ 项目的模型凭据。

密钥默认只用于本次运行。选择记住时，软件使用 Electron `safeStorage` 的系统加密，将加密结果保存到 `%APPDATA%/DafeiyuDouyinAPI/api-settings.json`；公开设置只返回是否已配置、接口地址、模型和记住状态。无法加密时只在内存使用，保存失败会提示原磁盘记录可能仍保留。

程序资源首次安装到 `%APPDATA%/DafeiyuDouyinAPI/runtimes/<资源摘要>/`。此目录独立于现有 DSH Desktop 的安装和用户目录，不复制其配置、密钥或会话。

在“刷视频时间”设置每日允许时段和每轮分钟数，点击开始后再提交浏览任务。支持多个时段及跨午夜时段，按北京时间计算；单轮默认 10 分钟，须为 1至1,000,000分钟的整数，或明确选择不限单轮时长。保存设置、重新开窗口或模型连续调用都不会延长已开始的一轮；到期后暂停视频并阻止后续浏览。

不限时长时，分钟框显示“不限”占位并保持可输入。填写分钟数会取消草稿中的不限开关，点击“保存时间设置”才生效；未保存的输入不会被状态轮询覆盖。自主观看控制区会显示后台记录的“上次自主观看停止原因”。这只展示已有原因，不会自动重试或重置预算。

“手动任务预算”默认 20 步、20 次工具调用、180 秒，可分别设为 1–10000步、1–10000次、10–604800秒，保存后用于后续手动任务。修改前须停止当前任务、自主观看和转发。它与视频时段、单轮截止及自主观看预算独立，任一上限先到便停，不自动续时；持续挑片可用自主观看。

音频默认关闭，可选本地 Whisper、MiMo 或 MiniMax。基础刷视频功能无需接入音频；本地路径仍需另装 Python、FFmpeg 和相应模型，云端后端需独立凭据。模型权重、个人媒体配置不随软件提供。

MiMo 的填写位置为“业务设置 → 音频与密钥 → 音频后端选择 MiMo → MiMo API Key → 保存音频 Key”。MiniMax 同样先选对应后端，再填 MiniMax API Key。Whisper 不需要云 Key。保存通过窄 Electron IPC 写入与插件共用的媒体 `.env`，这是本机明文配置，与主模型 Key 的可选系统加密保存不同；已保存值不会回显，也不经过本机 HTTP。

保存音频 Key 不开启音频、不切换已保存的运行后端，也不发起云请求。需要处理声音时，再明确设置“读取视频声音”和音频后端，点击“保存音频设置”。`MediaAdapter` 后续读取配置时刷新，无须为了更新文件重建适配器。更换 Key 前须停止正在执行的任务、自主观看和自动回复。

私信自动回复默认停止，只处理明确保存的最多两位已关注个人联系人，保留新消息基线、发送核对和每日预算。普通手动视频模型没有私信发送及可信转发工具。

分享名单位于“业务设置 → 好友互动 → 好友私信”：点击“读取联系人”，勾选好友，再“保存许可名单”。自主分享共用这份名单，不需要启用自动回复；分享总开关和次数上限仍需单独保存。

“自主分享”默认关闭，每日默认 3 次尝试，可设 1–20 次。开启总许可后，自主观看可在现有两位许可好友中自行选择好友与当前已观察作品，通过抖音官方分享界面发送作品卡片，不逐次要求选人或确认。界面显示名单和次数，不发送私信正文、人格或私密记忆，也不增加联系人。预留即计数，失败或人工核对不返还；不确定回执会暂停，须本人在抖音核对后记录“已送达／未送达”，不会自动重发。观看中可随时关闭总开关，无需先停止观看。旧接口仍保留明确选人、选作品的手动转发兼容入口。

“自主观看”可手动开始有限轮次再点击启动，也可在“视频观看”保存“每个允许时段自动开始一轮”。自动启动默认关闭，应用需保持运行；同一时段只自动一次，停止、失败和重启不补开。默认每轮30次模型请求，可填1–10000，两个入口每日合计最多20000次；同轮停止再开不清零。按单轮时长、时段和请求预算先到的条件停止，分享与评论仍分别受开关和限额约束。

两个入口共享自主 worker 锁，不能各开一条循环；软件可请求停止插件发起的自主观看，反之亦然。手动视频任务与手动转发需等自主观看停止。运行期间不能修改或清除模型配置；未开启时段自动启动时，程序重启不恢复自主循环；已保存许可则按共享时段回执检查下一次可启动时段。自动回复由用户明确启用，本次实现没有代用户修改模型配置或运行设置。

关闭软件会停止它拥有的 API 后台、任务及私信服务，释放客户端连接；专用 Edge 登录窗口继续保留。遇登录或验证码，需要在该窗口手动完成。

## 1.3 源码新增

以下为已有功能；当前软件与插件均通过分类设置操作问候、评论、日报和静默。

自动续火花默认关闭，沿用最多两位许可好友，在本人设置的时段内按手编人格生成简短问候。每位好友每天最多尝试一次；当天已有可靠发出互动、日期不明或有待回复消息时跳过。结果不确定则暂停等待核对，不自动重发；消息送达不代表平台火花已续上。

自主评论默认关闭，每日默认 3 次（可设 1–20），每轮默认 1 次（可设 1–3）。仅在有限自主观看中，由大肥鱼决定是否评论当前实际观察作品。正文另用一次只含该作品画面、标题和作者的请求生成，不读取人格、兴趣、联系人或私信，最多 200 字，禁止 @、链接和私人数据。同作品不自动重复，预留即扣次数，失败不返还；未确认则暂停。普通手动模型工具没有直接评论入口。当前真实抖音评论 DOM 尚未验收，无法识别输入区或按钮时要求手动打开评论区，不猜测已发布。

视频日报保存到共用 `memoryDir/reports/videos/YYYY-MM-DD.md`，只汇总留存作品标题、作者、规范链接、可核观看进度与互动，并标明记录覆盖范围。它不读取人格正文、私信或 QQ，不调用模型；同样事实重复生成不改稿，手编报告出现冲突时保留原文。

共用静默开关对受管页面持续静音，保留用户音量设置，不主动抢焦点；核实整个窗口都是受管页且没有登录验证时才尝试最小化。关闭静默不自动弹出窗口，“打开抖音”可再次显示。浏览器仍是有窗口 Edge，静默不等于 headless；真实抖音最小化后的持续播放尚待验收，不能保证网站不暂停。

安装、原生设置与日报流程参考 MIT 项目 [c1overzz/dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)，未引入其 Python 或 B 站 MCP。固定版本、复用边界与测试限制见 [功能复用与来源](../docs/reuse.md)。

## 与插件共用记忆

软件和新版 DSH 插件都读取 `%USERPROFILE%/.dsh/douyin-browser/runtime-location.json`。这是本机位置记录，目录名称沿用已有约定，不要求安装 DSH。记录内的 `memoryDir` 指向共同记忆文件夹，`memoryDbPath` 精确保留数据库文件名；软件设置中可直接打开该文件夹。

首次登记时优先保留已存在的旧中央库，写入其原位置，不复制、搬迁或清空数据库。新机器默认使用 `%USERPROFILE%/.dsh/douyin-browser/memory/shared.sqlite`。已有非标准数据库文件名也可登记；插件随后只读同一位置记录即可找到同一个文件，无需两边各自维护相同环境变量。

位置记录也可保留业务状态和媒体配置的绝对路径，不包含密钥、消息或数据库内容。损坏记录、目录与数据库不一致，或显式 `DEEPSEEK_SHARED_MEMORY_DB` 与已登记路径冲突时，软件拒绝启动，避免生成另一套记忆。修改或升级插件后需重新加载相应源码，才会读取新版定位逻辑。

人格独立位于同一 `memoryDir/persona/`：`role-card.md` 保留手编正文与自动生成区，`state.json` 保存实际观察及大肥鱼自己的兴趣依据。界面可打开人格目录、查看生效人格，并通过显式“编辑人格／保存人格”修改手编正文；兴趣方向、依据数量、更新时间和反思单独展示，不混入编辑框。外部更新或保存版本冲突会保留草稿，不自动覆盖或重试。

兴趣依据来自实际媒体进度和墙钟核算的观看时长、比例，以及已确认的继续停留、跳过、分享行为。帧仅说明采样画面，识别到某主题不等于喜欢；旧记录缺少行为依据时显示“待观察”。界面同时显示时长、比例、动作、判定依据与正负计数，同主题同作品不重复加权。

人格与兴趣仅按本机内部参考使用，不能改变工具权限、时间预算、许可名单或发送规则。代理兴趣不等于用户偏好。QQ 侧可见范围和公开分享授权尚未核实，不能因为两入口共用文件就向 QQ 群聊、公共导出或其他公开渠道传播。

前端通过同源 `/api/watch/state`、`/api/watch/start`、`/api/watch/stop` 读取和控制自主观看，手动启动固定传 `startSession:false`，时段调度使用明确保存的许可开始新轮；人格通过 `/api/persona` 和带 `expectedRevision` 的 `/api/persona/card` 读取、保存。打开人格目录使用无参 `window.douyinDesktop.openPersonaFolder()`，不开放任意路径或 HTTP 打开目录接口。

## 从源码构建

构建环境需 Windows x64、Node.js 24 和 pnpm。首次需要下载公开源码、Electron、Node 和 npm 依赖。固定源码缓存与运行资源均位于 `.cache/`，不提交 Git。

先在 `desktop` 安装桌面构建依赖和固定官方 UI 源码：

```powershell
pnpm --ignore-workspace install --ignore-scripts --frozen-lockfile
node node_modules/electron/install.js
node scripts/acquire-upstream.mjs
node scripts/stage-api-runtime.mjs --prepare-node-only
```

再按界面、后台、桌面入口、打包的顺序执行：

```powershell
cd ui-api
pnpm --ignore-workspace install --ignore-scripts --frozen-lockfile
node build.mjs
cd ..
node scripts/stage-api-runtime.mjs
node scripts/build-api-desktop.mjs
pnpm package:dir
pnpm package:portable

# 使用隔离目录、隐藏窗口检查最终便携包；不调用模型或操作真实抖音。
node scripts/verify-packaged-api.mjs
```

`--prepare-node-only` 只准备经官方压缩包与 SHASUMS 核对的 Node/npm。默认的 `stage-api-runtime.mjs` 也会自动完成这一步，再准备白名单领域文件、界面产物、私有 IPC worker 与两项后台 npm 依赖。它校验固定 Node/SQLite、媒体来源哈希、依赖锁文件及运行文件范围；运行目录中不包含 DSH Host、Cordis、账号配置或个人状态。前端许可证随界面产物保留，后台与 Electron/Node 的许可证随实际分发资源保留。

输出位于 `release-api/`，便携包文件名为 `Dafeiyu-Douyin-API-<版本>-win-x64.exe`。这是未签名的 Windows 开发版本，分发前仍需完成签名及其他机器的兼容性验收。
