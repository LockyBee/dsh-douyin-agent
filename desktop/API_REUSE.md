# 独立 API 软件复用记录

独立软件 1.1.0 直接连接用户填写的模型接口，不安装、启动或捆绑 DSH Host、Cordis、社区桌面壳或插件市场。复用已有浏览器领域层、有限视频轮次、许可私信服务、媒体可选模块和共享记忆存储，保留真实工具结果与原有安全边界。

界面复用官方 `deepseek-ai/deepseek-harness` 固定提交 `fb2c4b9e698e30edb738bca4cf0618587db7d203` 中可独立使用的 React UI primitives、主题样式。API 请求、软件设置与界面状态由本软件实现；没有模拟 DSH RPC 或冒充其运行会话。官方 MIT 全文保存在 `licenses/DeepSeek-Harness-MIT.txt`。

桌面壳使用 Electron，浏览器控制使用 Playwright，后台使用随包 Node.js 的 HTTP、SQLite 与进程 IPC。可选音频模块保留既有三个社区项目的 MIT 与来源说明，不捆绑个人凭据或模型权重。未使用鲸鱼插件的受限图片或音效资产。

主进程接收 API Key，通过本机进程 IPC 交给自有后台；普通 HTTP 接口不设置或返回密钥。可选记住密钥使用 Electron safeStorage 的系统加密。两种入口通过同一全局位置记录解析同一个记忆文件夹及精确数据库路径，不复制正在运行的 DSH 的凭据、会话或插件目录。

本次新增领域模块 `PersonaMemory` 与 `AutonomousWatch`，分别负责 `memoryDir/persona/` 中的手编人格、自动生成兴趣与实际观察，以及受原视频时限和持久预算约束的自主挑片。软件通过同源 REST 读写，原生插件复用 DSH 的模型路由和附件接口；两边读取同一文件、共用运行锁，任一入口可协作停止。人格目录由无参 `openPersonaFolder()` 桌面 IPC 打开，不提供任意路径打开能力。

自主观看由本人先开始有限轮次，再明确启动，默认每轮 30 次、最多 100 次模型决策，每日两入口合计最多 200 次。同一轮停止再开不清零，时限和预算先到即停；重启不自启，也不预约新轮。手动视频任务、转发与自主循环互斥，自主循环不发私信或转发。

人格正文的修改保留为显式用户操作；自动兴趣有来源、反思及更新时间，不能冒充用户偏好或授予权限。资料仅按本机内部参考使用，QQ 侧可见范围和公开分享授权尚未核实，不能公开导出或经 QQ 群聊传播。模型接口与自动回复由用户自行配置、明确启用，本次实现未代改设置。

新增界面沿用现有官方 React 组件，没有新增运行依赖；实际构建仍生成全部依赖及字体许可证。当前 UI 合成及许可检查 12／12、v6 原生 SDK 25／25 通过；根目录与 desktop 完整回归实际运行 237 项，230 项通过、0 项失败、7 项可选检查跳过，用时约 19.7 秒。27 项源码目录不等于当前 DSH 已加载。

1.1.0 的 `win-unpacked` 已实际打包回读，随包 Node 24.17.0、SQLite 3.53.0、27 项工具与 persona／watch 模块可导入，没有 DSH 运行包。新功能的界面验证来自两个临时 Edge 合成流程，真实 Electron 新窗口仍待验收；便携包结果与最终哈希另记于 [VERIFICATION.md](VERIFICATION.md)。旧 v5／22 工具与 1.0.1 软件的实测只作为历史记录保留。
