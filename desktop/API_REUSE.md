# 独立 API 软件复用记录

独立软件 1.3.2 直接连接用户填写的模型接口，不安装、启动或捆绑 DSH Host、Cordis、社区桌面壳或插件市场。复用与插件相同的 32 项领域定义、有限视频轮次、许可私信服务、媒体可选模块和共享记忆存储。

2026-10-23 同步采用现有 `WatchMode`、`AutonomousComments`、`DailyReport` 和已鉴权的本机 API；只补软件前端入口、连接恢复及版本校验，不引入新依赖。React 控件、Markdown 渲染沿用下述固定 MIT 源码。软件有自有 HTTP 和私有 IPC，因此不需要插件 1.3.2 的宿主 Connection／WebServer 兼容层；真实平台操作仍需另行验收。

界面复用官方 `deepseek-ai/deepseek-harness` 固定提交 `fb2c4b9e698e30edb738bca4cf0618587db7d203` 中可独立使用的 React UI primitives、主题样式。API 请求、软件设置与界面状态由本软件实现；没有模拟 DSH RPC 或冒充其运行会话。官方 MIT 全文保存在 `licenses/DeepSeek-Harness-MIT.txt`。

桌面壳使用 Electron，浏览器控制使用 Playwright，后台使用随包 Node.js 的 HTTP、SQLite 与进程 IPC。可选音频模块保留既有三个社区项目的 MIT 与来源说明，不捆绑个人凭据或模型权重。未使用鲸鱼插件的受限图片或音效资产。

主进程接收 API Key，通过本机进程 IPC 交给自有后台；普通 HTTP 接口不设置或返回密钥。可选记住密钥使用 Electron safeStorage 的系统加密。两种入口通过同一全局位置记录解析同一个记忆文件夹及精确数据库路径，不复制正在运行的 DSH 的凭据、会话或插件目录。

1.1.1 的“打开抖音”复用现有 CDP 连接、专用资料与聚焦逻辑，只补宿主入口和按钮。首页标题栏及首次 Key 表单均可打开，不需模型 Key、不请求 LLM、不开始计时，准备页强制暂停；已有自主观看运行时只聚焦现有页。原生 v7 另通过 commands 服务提供 `/douyin-open`，命令不增加模型工具权限。

音频 Key 表单复用官方 Input，修正本地选择器以免把包装 span 当作字段标题；仅外层绘制焦点环，密码与数字原生功能保留。MiMo 路径为“业务设置 → 音频理解 → 音频后端选择 MiMo → MiMo API Key → 保存音频 Key”，MiniMax 对应填写。窄 `saveMediaKey({backend,apiKey})` Electron IPC 调用本机 writer，只更新共享媒体 `.env` 中的对应字段，不经本机 HTTP、不回显、不自动启用音频。该文件为明文本机配置；默认 `MediaAdapter` 每次读取时刷新，Whisper 不需要云 Key。

`PersonaMemory` 与 `AutonomousWatch` 分别负责 `memoryDir/persona/` 中的手编人格、自动生成兴趣与实际观察，以及受原视频时限和持久预算约束的自主挑片。软件通过同源 REST 读写，原生插件复用 DSH 的模型路由和附件接口；两边读取同一文件、共用运行锁，任一入口可协作停止。人格目录由无参 `openPersonaFolder()` 桌面 IPC 打开，不提供任意路径打开能力。

1.4.1复用VideoLimits、AutonomousWatch和Node定时器，补共享时段占位，每个允许时段最多自动一轮；默认关闭，需本人保存。请求预算为每轮1–10000、默认30，每日两入口合计20000，同轮不重置。已有轮次的停止、失败、重启不触发本时段补开。新增软件更新与图标来源及限制见[1.4.1说明](../docs/features-1.4.1.md)。

1.2.0 的 `TaskLimits` 复用现有手动 `ApiAgent` 执行边界，默认 20 步、20 次工具、180 秒，可由用户设置为 1–1000 步、1–1000 次、10–86400 秒。它不改 `VideoLimits` 时段、单轮截止、watch 请求预算或 DSH 外层模型预算。界面通过 `/api/task/limits` 轮询及显式保存，保留未保存草稿。

`AutonomousShare` 复用现有许可名单，通过 Playwright 操作抖音官方分享 UI，不接私有发送接口。总开关默认关闭，每日默认 3 次尝试、可设 1–20 次；开启后由 watch 自选现有两位许可好友及当前已观察作品，发送官方作品卡片，不逐次确认。它不转发正文、人格或私密记忆。预留即计数，不确定或异常残留暂停后续发送；须本人核对结果，不能靠重新开关清除或自动重发。关闭许可可在观看运行时保存。

偏好根据实际媒体进度与墙钟核算的观看时长、比例及已确认的 stay／skip／分享行为判定。帧和模型主题只是观察及选题提案；旧记录无行为依据时待观察。界面展示时长、比例、动作、依据和正负计数，不把模型自述当作已验证喜好。

人格正文的修改保留为显式用户操作；自动兴趣有来源、反思及更新时间，不能冒充用户偏好或授予权限。资料仅按本机内部参考使用，QQ 侧可见范围和公开分享授权尚未核实，不能公开导出或经 QQ 群聊传播。模型接口与自动回复由用户自行配置、明确启用，本次实现未代改设置。

新增界面沿用现有官方 React 组件，没有新增运行依赖；实际构建仍生成全部依赖及字体许可证。1.1.0 的 UI 合成及许可检查 12／12、v6 原生 SDK 25／25 通过；该阶段根目录与 desktop 完整回归实际运行 237 项，230 项通过、0 项失败、7 项可选检查跳过，用时约 19.7 秒。27 项源码目录不等于当前 DSH 已加载。
