## 打包与本机窗口

electron-builder 实际生成 `release-api/win-unpacked/大肥鱼抖音助手.exe`。打包回读检查通过：随包物理 Node、内存 SQLite、Playwright 与 22 项领域工具定义均可用，未包含 DSH 运行包。

通过 Windows 桌面操作打开该 EXE，实际窗口标题为“大肥鱼抖音助手 · 独立 API 版”，首次显示 API Key 表单及原有中央记忆目录。后台 bootstrap 与全局位置记录均指向原有的同一个数据库文件；没有为软件建立另一套视频记忆。

仅使用合成 Key 检查了实际桌面 IPC、系统加密保存、关闭后重启恢复及清除。磁盘设置中有加密字段，没有明文 Key 字段或合成 Key 原文；清除后加密字段移除、后台回读 `configured:false`。没有验证该合成 Key 可访问模型服务。

正常关闭窗口后，自有 Electron 与 Node 后台进程均退出，原有 DSH Desktop 继续运行。重启后的音频、私信自动回复均关闭，视频轮次为已结束。合成 Key 已清除，软件等待用户自行配置。
