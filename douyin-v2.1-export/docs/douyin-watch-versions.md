# 抖音自主观看 · 版本对照表

本文件记录各版本编号与特征，供 A/B 对照使用。

## v0 · 原生严格版（插件出厂行为）

**代码状态**：原始未改动。可用备份（同目录）：

- `autonomous-watch.mjs.bak-20261106`
- `core.mjs.bak-20261107`
- `tool-definitions.mjs.bak-20261107`

**工作流**：搜一次只试第一条 → 每步硬校验（停留前后同一条、换片必须确认）→ 任一校验失败整轮 `failed`/`needs_user`，需人工重启。

## v1 · 被动记账版（2026-11-07 中段）

判断与播放解耦：不暂停、模型只记账、换片交连播。逐步加入事件日志、搜索筛选、图文兜底。

## v1.1 · 当前版本（2026-11-08）

在 v1 基础上完成下列能力（累计补丁 1–46）：

| 能力 | 落地 |
|---|---|
| 被动模式（判断不打断播放） | ✅ |
| 搜索筛选：最新发布 + 一周内 + 仅视频 | ✅ 悬停「筛选」后依次点击 |
| 按天去重（跨轮、跨重启） | ✅ `state/seen/YYYY-MM-DD.json` |
| 离题 / 口味 / 重复 三类分流 | ✅ `state/noise`、`state/taste`、`skip_duplicate` |
| 直播卡识别与滑走 | ✅ `live-avatar` / 「直播中」 |
| 播完不重播、重播熔断 | ✅ 播放位置倒退 ≥2 次强制换片 |
| 滑走没变化 → 回推荐流 | ✅ `watch.loop_break` |
| 浏览器关闭 → 干净收尾 + 日报 | ✅ `watch.browser_closed` |
| 四主题全空 → 结束并视为今日完成 | ✅ `watch.topic_exhausted` |
| 版本标记 + 全事件日志 | ✅ `watch.version` = v1.1 |

**已知边界**：

- 不点赞、不评论、不关注、不私信
- 改代码需备份 + 提权 + **重启 DSH** 才生效
- 频繁刷可能触发平台安全验证（需人工处理）

## v2.1 · 当前版本（2026-11-10 定稿）

在 v2.0 基础上（补丁 61–66）落定：离题立即换片、主题游标推进、直播卡不废主题、搜索重试、阻断原因细分、日报离题清单、Word 导出。

**已知问题（待 11-11 验证）**：`douyin_next` 在双播放器页面全部返回 `switch-control-ambiguous`（candidateCount=2），实际换片靠连播；由此 `loop_break` 多为假警报，主题会被提前推进。计划验证“关闭抖音客户端、只留网页版”后是否仍复现；若仍复现则改 `core.mjs`（候选选择或方向键换片）。

代码常量：`WATCH_VERSION = 'v2.1'`

## v2.0 · 历史版本（2026-11-09 定稿）

在 v1.1.250 基础上追加（补丁 51–65），核心里程碑：

| 能力 | 说明 |
|---|---|
| 更多菜单读取 | `douyin_more` 打开抖音自绘菜单并读选项（清屏/评论/赞/主页/推荐/分享/不感兴趣/举报） |
| 快捷键能力 | `douyin_more({press:'R'})` 按白名单键，R=不感兴趣（实测生效，页面提示“操作成功，将减少此类视频出现”） |
| 离题自动处置 | 同一作品连续 3 天判 `offtopic` → 第 3 天判定当场按 R，记 `watch.auto_not_interested` |
| 离题立即换片 | 判 `offtopic` 后同一秒内点下一条（`watch.offtopic_next`），不再白看 30 秒 |
| 跳出回主题 | `loop_break` 后回主题搜索而非推荐流，并推进主题游标（`recoverTopic({advance:true})`） |
| 直播卡不废主题 | 打开结果是直播卡时换下一个候选，不判整轮 `needs_user` |
| 搜索重试 | 搜索未就绪时等 1.5 秒重试一次（`watch.topic_retry`） |
| 阻断原因细分 | 报错写明「验证/登录/直播卡/身份冲突」，不再笼统 |
| 日报离题清单 | `daily-report.mjs` 原生输出「离题清单（连续 3 天自动不感兴趣）」章节 |
| Word 导出 | `md2docx.py` 把日报转成排版良好的 docx（封面/两行列表/定宽表格/页码） |
| 热重启 | 每次 `douyin_watch_start` 重新加载 `autonomous-watch.mjs`，调参无需重启 DSH |

代码常量：`WATCH_VERSION = 'v2.0'`（`autonomous-watch.mjs`）

**已知遗留**：抖音偶发安全验证弹窗（瞬时出现），会打断单个主题；`梨型身材` 等主题搜出的多为带货内容，会快速判离题。
